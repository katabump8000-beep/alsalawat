رحلة البكالوريا + Gemini API

هذه الحزمة معدّة للنشر على Cloudflare Pages (وليس GitHub Pages وحده)، لأن استدعاء Gemini يحتاج إلى دالة خادم لحماية المفتاح.

الخطوات:
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو اربط المستودع بـ Cloudflare Pages.
2. في Cloudflare Pages، اختر المشروع المرتبط بالمستودع، ثم Settings > Variables and Secrets.
3. أضف متغيراً سرياً باسم GEMINI_API_KEY وضع قيمة مفتاح Gemini الجديد فيه. لا تضع المفتاح داخل index.html أو Git.
4. انشر الموقع من جذر المشروع. يجب أن يبقى المسار functions/api/ask.js كما هو.
5. افتح الموقع وجرّب مساعد الدراسة.

مهم:
- إذا سبق أن شاركت مفتاحاً حقيقياً في محادثة أو كود، ألغِه وأنشئ مفتاحاً جديداً.
- لا تضف أي ملف يحتوي على المفتاح إلى المستودع.
- المؤقت والسجل المحلي يعملان على الجهاز نفسه فقط.
